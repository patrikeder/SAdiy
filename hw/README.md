# Hardware

Every stage is a separate PCB with contact options for the SBC (control, supply) and for measurement (SMA, headers, test points).

## Start here

| Need | File |
|---|---|
| What the photos show and how the assumptions held up | [as-built.md](as-built.md) |
| Board hierarchy, RF chain, power tree (diagrams) | [hierarchy.md](hierarchy.md) |
| Wire a BeagleBone Black | [wiring-bbb.md](wiring-bbb.md) |
| Wire a Raspberry Pi | [wiring-rpi.md](wiring-rpi.md) |
| Net list and straps (generated) | [netlist.md](netlist.md) |
| RF cabling between boards | [wiring.md](wiring.md) |
| Per-board connector and test-point notes | `boards/` |
| What to measure where | [test-points.md](test-points.md) |
| Parts still missing | [todo-parts.md](todo-parts.md) |

Diagrams are in `diagrams/` (SVG and PNG), generated by `tools/gen_diagrams.py`.

## Boards

| Board | Page | Control from SBC |
|---|---|---|
| SBC (BBB or RPi) | `boards/sbc.md` | n/a |
| PE4302 attenuator | `boards/pe4302.md` | 6 GPIO lines V1..V6 (parallel, no serial interface) |
| 30 dB amp | `boards/amp.md` | none |
| AD831 mixer | `boards/ad831.md` | none |
| Detector | `boards/detector.md` | none (analog out to ADC) |
| ADF4351 synthesizer | `boards/adf4351.md` | SPI + lock-detect GPIO |

`power.md` is not written yet; the plan is in the power tree diagram.
