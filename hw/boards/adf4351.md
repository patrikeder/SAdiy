# ADF4351 synthesizer board (LO)

Photo: [photos/adf4351-board.jpg](../photos/adf4351-board.jpg). Silkscreen: `ADF4351X EVAL Board 2019_1_v1.4`.

## What the photo shows
- Reference: on-board oscillator marked `V25.000 KDSH 4D`, so the reference is **25 MHz**. An SMA `MCLK` input is next to it for an external reference.
- Outputs: two SMA connectors, `AOUT-` and `AOUT+` (the differential RF outputs). Both have cables fitted.
- Power: a DC barrel jack labelled **5 V** (with a polarity symbol and a red LED) and an `AMS1117 3.3` regulator on the board. The chip is supplied from the on-board 3.3 V.
- 2 x 5 pin header, left column `GND CE LE CLK LD`, right column `3V3 GND DAT MUX PDR` (rows from the top: GND/3V3, CE/GND, LE/DAT, CLK/MUX, LD/PDR).
- Silkscreen `Lock_Flag` next to an LED: lock detect indicator.

## Facts

| Item | Value |
|---|---|
| Part | ADF4351, 35 to 4400 MHz, 25 MHz PFD with this reference |
| Supply | 5 V on the DC jack; AMS1117-3.3 on the board. The `3V3` header pin is the regulator output: **do not feed it** |
| Logic | 3.3 V, SPI mode 0, MSB first, 32-bit words; `LE` latches on the rising edge |
| Header | `CLK`, `DAT`, `LE` = SPI; `LD` = lock detect output (use this); `MUX` = MUXOUT (unused); `CE` = chip enable; `PDR` = RF power-down pin (PDBRF), high = RF outputs on |
| RF output | -4 to +5 dBm in 3 dB steps; harmonics only 10 to 20 dB down (low-pass filter needed behind it) |

Use one output for the LO and terminate the other in 50 ohm (the outputs are complementary).

## Control from the SBC
- `CLK`, `DAT`, `LE` to the SPI0 pins (`../wiring-bbb.md`, `../wiring-rpi.md`), `LD` to a GPIO input, `GND` to the star point.
- `CE` and `PDR` must be high: tie them to the board's `3V3` pin, or keep CE on an SBC pin (`SYN_CE`). Measure first whether the board already pulls them up.
- The 25 MHz reference matches `synth.ref_hz` and `synth.pfd_hz` in `config/default.toml`.
- Driver: `src/sadiy/drivers/adf4351.py` (register packing still to be written).
